## Что это

**LLMborn** — интерактивная игра на чистом HTML/CSS/JS. Ни сборки, ни зависимостей, ни сервера: скачал, открыл `index.html` — и играешь. Всё обучение считается прямо в твоём браузере.

Идея простая: объяснить, как обучается ИИ, нельзя картинками. Поэтому здесь всё, о чём рассказывает текст, тут же можно потрогать руками — покрутить, перетащить, поймать и не поймать.

## Уровни

| # | Уровень | Что ты делаешь руками |
|---|---------|------------------------|
| 1 | **Токены** | Крутишь длину токена и смотришь, как текст режется на куски; собираешь слова из токенов |
| 2 | **Эмбеддинги** | Раскладываешь слова по смысловым группам на карте, потом двигаешь вектор и смотришь, как меняются ассоциации |
| 3 | **Вес нейрона** | Подбираешь веса и смещение, чтобы нейрон решил логику «ИЛИ», и сравниваешь с автоматическим обучением |
| 4 | **Прямой проход** | Кликаешь по узлам сети и видишь, из чего сложилась каждая цифра; угадываешь ответ сети |
| 5 | **Ошибка (loss)** | Выставляешь вероятности и ищешь минимум суммарной ошибки на кривой перекрёстной энтропии |
| 6 | **Градиентный спуск** | Катишь шарик по рельефу ошибки; локальные минимумы приходится обходить вручную |
| 7 | **Обучение по эпохам** | Настоящая нейросеть 2→4→1 учится в браузере: тот же прямой проход, та же ошибка, тот же спуск |
| 8 | **Генерация текста** | Угадываешь продолжение по распределению вероятностей и крутишь температуру |
| 9 | **Итоги** | Схема всего цикла обучения и квиз на 6 вопросов |

## Запуск

Открой `index.html` двойным кликом — всё.

Чтобы запустить на локальном сервере (например, чтобы GitHub Pages работал как надо):

```bash
python -m http.server 8000
# затем открой http://localhost:8000
```

## Что внутри

```
llmborn/
├── index.html          # разметка оболочки
├── app.css             # стили
├── engine.js           # движок: роутер уровней, прогресс, звук
├── levels.core.js      # уровни 1–4
├── levels.adv.js       # уровни 5–9
├── logo.svg            # знак
└── logo-wordmark.svg   # знак + название
```

- **Без зависимостей и сборки.** Vanilla JS, ES-модулей нет, всё работает с `file://`.
- **Честная математика.** На уровне 7 — настоящий backprop: 2 входа, 4 скрытых нейрона на `tanh`, выход на сигмоиде, полный батч, momentum, перекрёстная энтропия. Точки на графике — реальные точки обучения, а не анимация.
- **Параметры подобраны численно.** Поведение learning rate (0.005 буксует, 0.3 даёт победу за ~250 эпох, 8 ломает сеть) и геометрия рельефов проверены симуляцией, а не «на глаз».
- **Прогресс сохраняется** в `localStorage`, точки на верхней полосе кликабельны, ссылка `index.html#7` открывает нужный уровень.
- Звук (WebAudio) включается и выключается в шапке.
